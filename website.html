リラクゼーションサロン 公式サイト構築

サロンの公式サイトを、要件調査・情報設計・デザイン・WordPress構築まで一人称で担当して制作しました。 未経験だったWordPress構築は、生成AI(Claude Code)を実装パートナーとして活用しながら、 設計判断と検証を自身で行うことで完成させています。

WordPress Claude Code Photoshop 情報設計 テーマ開発 レスポンシブ対応

設計のポイント

業界の商習慣を調査した上で、更新頻度の高い「出勤情報」「スタッフ紹介」をCMS化し、 制作者がいなくても店舗側で日々更新できる運用設計にしました。 集客チャネルを踏まえて外国人のお客様向けページも用意し、 「作って納品して終わり」ではなく公開後に運用が回ることをゴールに設計しています。

AIの活用について

WordPressのテーマ開発は本案件が初挑戦でした。実装はClaude Codeとの対話で進め、 要件定義・情報設計・デザイン判断・動作検証は自身で担当。 「AIに作らせる」のではなく「AIと組んで、自分の作れる領域を広げる」進め方を実践した案件です。
